# Support

Use GitHub Issues for reproducible bugs and feature requests.

For configuration questions, include:

- qbit-allocator version or commit
- qBittorrent version
- deployment method, such as Docker Compose or local `dotnet run`
- sanitized allocator configuration
- expected save path and actual save path
- relevant logs with credentials, cookies, private URLs, and real hashes removed

This project is intended for lawful download and storage-management workflows.
